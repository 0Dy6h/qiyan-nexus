Qiyan Nexus 项目原理图

面向特应性皮炎医生与科研人员的中医药证据工作台：MVP-A 证据工作台已收尾，MVP-B 原始 slice 基本落地，C 阶段 provider、retrieval、grounding 与多语 embedding 底座部分提前完成；默认路径仍保持离线、可复现、可治理。

Snapshot: 2026-06-10
MVP-A: closed
L2: not flipped

默认运行路径

  • • MVP-A 证据工作台 100% 收尾完成；文献、RAG、PDF、评估、合规与导出链路可内部走查。
  • • RAG 默认 deterministic provider + keyword bridge retrieval，返回引用卡、grounding metadata、SLI 与固定免责声明。
  • • `/literature` 已有四来源视图：全部来源、PubMed 实时、CNKI sample、上传 PDF。

分层原则

  • • router 接 HTTP 契约，service 编排业务，repository 统一读写 seed/runtime 状态。
  • • runtime 默认 JSON，`QIYAN_STATE_BACKEND=sqlite` 可切到本地 SQLite；两者仍是开发态，不是生产数据库。
  • • network 当前是 MVP-B mock 但链路完整：seed graph、GO/KEGG 富集、SVG 图谱、键盘可访问与后端 Markdown 报告。

治理边界

  • • L2/default preview 不翻转；真实 LLM、BGE/NLI、多语 embedding 都只在显式 env/smoke 路径启用。
  • • 2026-06-10 已接 `bge-m3` 与 `multilingual-e5-large` 底座，但真实模型 cross-lingual eval 尚未运行。
  • • 产品只聚焦 AD 医生/科研端，所有 AI 输出保持“非诊断结论、需结合临床。”
