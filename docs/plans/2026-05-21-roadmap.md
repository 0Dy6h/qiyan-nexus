### 3.1 阶段 A：MVP-A 收尾期（2026-05-21 → 2026-06-04）

**出口标准**：MVP-A 100%，可以对内部 1-2 个目标用户做封闭走查。

| Slice | 主题 | 估计 | 验收 |
|---|---|---|---|
| A1 | 真实 PubMed 抓取（最小可用） | 2 天 | `/api/literature/sync?source=pubmed&q=...` 拉取并合并入 runtime；不替换 seed；命中数 >=10 |
| A2 | 最小访问控制 | 1.5 天 | 中间件级 X-Access-Token；白名单从 env 读；CORS 不变；测试覆盖 401/200 两路 |
| A3 | RAG 答案导出（Markdown） | 1 天 | `/rag` 增加"导出答案"按钮，下载 .md，含 question + answer + citations + disclaimer + timestamp |
| A4 | Playwright E2E 起步（仅 1 条主路径） | 1 天 | 装 Playwright；写一条 `/literature → 选条目 → 跳详情 → /rag → 问答 → 看 citation` 串联；CI 命令 `pnpm e2e` |
| A5 | 真实中文 PDF 抽取人工验收 | 0.5 天 | 上传 2-3 个真实中文文本型 PDF，确认 `pypdf-text-preview` 返回中文不乱码；不通过则回退到 fallback 文案 |
| A6 | 合规页扩展 | 0.5 天 | `/compliance` 加上「数据来源说明」「PDF 版权声明」段；page-shell test 同步 |

总计 ≈ 6.5 工作日。

### 3.2 阶段 B：MVP-A 真实化 + MVP-B 起步（2026-06-05 → 2026-07-02）

**目标**：MVP-A 在 deterministic 基础上保留可切换的 LLM 钩子；MVP-B 网络药理学任务壳跑通。

| Slice | 主题 | 估计 | 验收 |
|---|---|---|---|
| B1 | LLM provider 接口抽象（不接真实模型） | 1 天 | `app/services/llm/provider.py`：`generate_answer(question, citations) -> AnswerDraft`，提供 `DeterministicProvider`（当前行为）与 `MockClaudeProvider`；通过 env `QIYAN_LLM_PROVIDER` 切换 |
| B2 | RAG eval 扩展到 50 题 | 2 天 | 新增 30 题，覆盖 herb / formula / target / pathway 早期问题；保持 ≥95% pass rate |
| B3 | 网络药理学任务壳（前后端） | 3 天 | `/api/network/analyze` 已存在 mock，扩展为接受 query+analysis_type，落 runtime state；前端新增 `/network` 页面展示「成分-靶点-通路-疾病」链 |
| B4 | herb / compound / target / pathway sample 数据集 | 2 天 | `backend/data/network/sample_*.json`，与 literature 通过 `related_entity_ids` 互链；不接 KEGG/STRING |
| B5 | RAG citation → network entity 双向跳转 | 1.5 天 | citation 上的 entity tag 可点击跳到 `/network?focus=...`；反向 `/network` 节点上"相关文献" |
| B6 | 数据来源切换面板（合规） | 0.5 天 | `/literature` 显式区分「PubMed 实时」「CNKI sample」「上传 PDF」三类，banner 文案随选择切换 |

总计 ≈ 10 工作日（含缓冲）。

### 3.3 阶段 C：MVP-B 推进 + MVP-A LLM 化（2026-07-03 → 2026-08-13）

**目标**：真实 Claude API 接入 RAG；网络药理学有可发布的最小分析；为 MVP-C 分子对接保留对象骨架。

| Slice | 主题 | 估计 | 验收 |
|---|---|---|---|
| C1 | OpenCode Go live provider 优先闭环 | 3 天 | `QIYAN_LLM_PROVIDER=opencode_go` 本地 smoke；优先 OpenAI-compatible tool/function calling，必要时回退 structured claims v3；保留 deterministic provider 作为回退 |
| C2 | Citation grounding（tool use 强制） | 3 天 | LLM 必须通过 `cite_chunk` tool 才能引用；超出 citation 集合的引用 reject；eval 加 grounding 指标 |
| C3 | Embedding + 简单向量检索 | 4 天 | 不上 pgvector；用 `numpy + faiss-cpu` 单文件 index；与现有 keyword retrieval 并行；ablation：keyword-only vs hybrid eval |
| C4 | 网络药理学富集分析（mock） | 3 天 | 接 sample 数据计算 GO/KEGG 富集（用本地 .json 字典模拟，不调 STRING）；任务态 queued→running→completed |
| C5 | 分析报告导出（Markdown + 图片占位） | 2 天 | `/network/task/{id}/report` 返回 .md；含链条、靶点、参数版本、citations、disclaimer |
| C6 | MVP-C 概念对象 schema 预留 | 1 天 | `app/schemas/molecular.py`：protein / ligand / simulation_task 仅类型定义、无 router |

总计 ≈ 16 工作日。

## 4. 工程纪律（无变更项）

### 4.1 验证 gauntlet（提交前必跑，全绿才提交）

Backend：
```bash
cd backend && .venv/bin/python -m ruff format --check app tests \
  && .venv/bin/python -m ruff check app tests \
  && .venv/bin/python -m mypy app \
  && .venv/bin/python -m pytest -q \
  && echo "BACKEND GAUNTLET GREEN"
```

Frontend：
```bash
cd frontend && pnpm test && pnpm typecheck && pnpm build \
  && echo "FRONTEND GAUNTLET GREEN"
```

E2E（阶段 A3 后）：
```bash
cd frontend && pnpm e2e && echo "E2E GREEN"
```

### 4.2 TDD 节奏（按 AGENTS.md）

- 行为代码：**failing test → implement → refactor**，commit 小切片。
- 文案/UI shell 改动：源码字符串断言（现有 `page-shell-consistency.test.ts` 模式）。
- 不要批量 refactor 再补测试。

### 4.3 提交与分支

- 当前 branch `chore/repo-cleanup-docs` 已含 feat commit，**push 前请拆分或重命名**为 `feat/<slice-name>` 系列。
- 单 slice 单 commit；handoff 文档与代码同 commit。
- push 时通过 Windows 代理：`HTTPS_PROXY=http://172.26.0.1:7897 git push origin <branch>`。

### 4.4 安全与合规

- `disclaimer` 字符串 `非诊断结论、需结合临床。` **byte-identical**，任何 service / 前端断言都依赖它。
- `.env*` 与 `backend/uploads/` 与 `backend/data/runtime/` 三类绝不入仓。
- 接入真实 LLM（C1）前：`security-review` skill 强制跑一遍；写 ADR 记录 token 预算与 PIPL 数据流向。
- 接入访问控制（A2）后：security-review 也强制跑一遍。

- UI 视觉调整 → 用 `clamp(20px, 4vw, 48px)` 与 `#0d9488 ~ #14b8a6` 主色；不引入新样式层。

## 7. 风险与对冲

| 风险 | 触发条件 | 对冲 |
|---|---|---|
| Next 16 / React 19 / antd 6 三个 major 同时新，社区资料少 | 引入新组件时报错 | 当前 ADR-0009 已记录；遇到 antd 6 不可用时降回 inline markup |

| Claude API 成本超预算 | C1 上线后单问 > $0.01 | 强制 prompt caching；citation chunk 用 cache_control；超阈值切回 deterministic |
| 网药 sample 数据与真实数据库 schema 不兼容 | MVP-B 后期想接 PG 时 | B3 数据模型严格按 ADR-0010 概念命名（herb / formula / compound / target / pathway / disease） |
