# gpt-5.5 baseline attempt — HTTP 401 fallback

> Date: 2026-06-09
> Scope: Phase 2A pre-baseline attempt for router.team `gpt-5.5`
> Status: not a valid live baseline

## Purpose

Following the post-MVP-A execution plan, this run attempted to rebuild the
`opencode_go` live-provider baseline after the 2026-06-08 switch from historical
`deepseek-v4-flash` to router.team `gpt-5.5`.

The intended baseline dimensions were:

- provider latency
- token usage
- grounding pass / blocked / skipped counts
- NLI pass rate under the `BGE=0.3 + NLI=0.5` evaluation profile

Cost was intentionally not estimated because the current router.team `gpt-5.5`
contract price is not recorded.

```text
OpenCodeGoProvider falling back to deterministic: HTTPStatusError status=401
```

## Interpretation

This run is **not** a valid router.team `gpt-5.5` live baseline.

The pipeline entered `opencode_go` live mode, but the gateway returned HTTP 401
for all 10 sampled questions. The application then followed the expected safety
path and fell back to deterministic answers. Therefore:

- `provider_latency_ms` in this artifact reflects fallback behavior, not
  `gpt-5.5` latency.
- `grounding.status="skipped"` reflects deterministic fallback, not
  live-provider grounding.
- token usage and NLI pass rate are unavailable.
- cost remains intentionally unavailable.
