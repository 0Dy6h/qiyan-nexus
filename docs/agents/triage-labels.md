# Triage 标签

技能规范使用五个标准 triage 角色。本文件将这些角色映射到本仓库问题追踪器实际使用的中文标签。

| 技能规范角色 | 本仓库标签 | 含义 |
|---|---|---|
| `needs-triage` | `待评估` | 维护者需要评估此问题 |
| `needs-info` | `需补充` | 等待提问者补充更多信息 |
| `ready-for-agent` | `Agent可接` | 规格充分，AI Agent 可无上下文接手 |
| `ready-for-human` | `需人工` | 需要人工实现 |
| `wontfix` | `不处理` | 不会执行 |

当技能提到某个角色（如"应用 AFK-ready 标签"），请使用本表中对应的中文标签。

在本地 Markdown 问题文件中，标签记录为文件头部的 `状态:` 字段值。
