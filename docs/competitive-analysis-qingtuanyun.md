# 竞品参照：青团云（qingtuanyun.com）对标分析

- 日期：2026-09-03
- 性质：竞品参照笔记，不构成决策记录，不改变 ADR-0017 / ADR-0018 已冻结的产品边界。若未来要据此立项或扩边界，必须走独立 ADR/修订门禁。
- 信息来源与边界：仅基于公开官网营销面（2026-09-03 抓取首页与 `/intro`，均为同一 SPA 壳）与公开搜索结果。**登录后的实际产品功能、定价、用户规模均未实测、未知**；下文所有「青团云」描述都应理解为营销面观察，不是产品实测结论。

## 1. 青团云概况（公开观察）

定位：「科研数据分析与学习平台」，登录制 Web SaaS（163 邮箱客服 + 微信客服，有分类反馈流程：技术问题优先排查、功能建议进需求池）。公开营销面可见的模块：

| 板块 | 公开描述（原文摘录） |
|------|----------------------|
| 组学分析 — 转录组 | 数据导入、差异分析、富集分析与 WGCNA 等全流程 |
| 组学分析 — 单细胞 | 质控、聚类、注释与差异富集等 Seurat 流程 |
| 组学分析 — 空间组学 | 空间转录组可视化与区域解析 |
| 数据管理 — 文件管理 | 上传、组织、管理分析数据 |
| 数据管理 — 公共数据 | 预置参考基因组与示例数据集 |
| 数据管理 — 历史分析 | 查看、预览、下载历史分析结果 |
| 独立导航卡片 | 基础绘图、生信分析、网络药理学、科研服务（详情在登录墙后，未实测） |

形态判断：泛科研领域的「工具 + 内容 + 人工服务」平台，覆盖组学分析、绘图、网络药理学与付费科研服务；网络药理学只是其众多板块之一，未见任何 provenance / 可复算 / 判定纪律的公开宣称。

## 3. 启研的差异化定位

1. **纪律面是护城河，不是包袱**：青团云这类平台帮用户快速产出「论文形状」的网络结果，但不回答「结果可不可信、可不可以复算、有没有人复核过」。启研的 raw artifact 冻结、lineage、adjudication 审计流与 source-bound 装配计划正是针对这个空位。ADR-0018 背景中「市面网络药理平台多数止步于数据库预测」的判断，青团云是一个活例证。
2. **组学验证层 vs 组学工具**：青团云卖的是「替你跑完组学分析」；启研的 Gate 3 方向是「用真实测量数据给网络药理学的预测边做验证」（`omics_validated` 证据等级，6 项升级条件）。同一批数据，两种完全不同的产品命题。
3. **窄域 vs 全科**：启研锁定特应性皮炎 + 中医药科研，语料（344 篇 PubMed）、术语词典、评测题集都为该领域调校；这是青团云泛科研平台不会为单病种做的事。
4. **诚实的就绪语义**：`formal_network_ready=false`、「能记录判定 ≠ 已有人判定」这类边界在营销驱动的竞品语境中反而是稀缺卖点（面向科研人员时，「不夸大」本身就是信任资产）。

## 4. 可借鉴清单（UX 级，不扩产品边界）

- **历史分析三件套「查看、预览、下载」**：对照检查 network task 的 result / report / export 读取链路是否有同等顺滑度（注意：report GET 是只读观察接口，不得借读取推进状态）。
- **公共数据预置**：对应启研的 seed corpus 与离线 raw artifact 模板；可评估是否把受支持的 raw artifact 样例做成更顺手的入口（仍走服务端 SHA-256 + trusted manifest 纪律）。
- **分类反馈流程（技术问题 vs 需求池）**：研究者本人是当前唯一用户，暂无运维压力，但未来内部预览扩人时可参照。

## 5. 不跟进清单（冻结边界，逐条有依据）

| 不跟进项 | 依据 |
|----------|------|
| 泛病种 / 泛科研扩展 | ADR-0017：病种仅特应性皮炎 |
| 通用组学工具（单细胞/空间组/绘图/生存分析） | ADR-0018：组学数据只作显式 opt-in 验证层 |
| 分子对接 / MD 提前实现 | ADR-0010：MVP-C 仅 schema 概念预留 |
| 课程内容、付费科研服务 | 用户仅医生/科研人员端；产品主轴是科研辅助工具，不是内容与服务生意 |
| 以竞品功能清单倒逼排期 | AGENTS.md 当前开发原则：小步提交、按网络药理学协议→lineage→复算→真实闭环推进 |
