# 中英文文献分源索引策略

> **状态：历史规划提案。** 本文不再定义当前默认实现；JSON seed/runtime、可选 SQLite、PubMed 入口与检索边界以 `docs/current-state.md` 及后续 ADR 为准。

MVP 预算 ¥960 约束下，中文文献（约 1000 篇）手动收集 PDF → 预建 PostgreSQL + pgvector 本地索引；英文文献（约 500 篇）通过免费 PubMed E-utilities API 实时检索。

**为什么不是统一 API 方案**：知网和万方无免费公开 API，均需机构订阅。PubMed 的 E-utilities API 完全免费。成本约束直接排除了中文统一 API 方案，但英文 PubMed 恰好可行。

**为什么英文不全预建索引**：500 篇英文量适中，PubMed API 免费且实时查询可获得最新文献。若未来英文量超过 2000 篇或需要离线检索，再考虑预建英文索引。

## Considered Options

1. **双语都预建索引** — 工作量大（手动收集 1500 篇），且丧失了英文文献的时效性
2. **双语都走 API** — 知网/万方无免费 API，预算不可行
3. **中文预建 + 英文 API**（选定）— 唯一在预算内同时覆盖中英文的方案
