# Pre-dev planning archive

本目录保存 Tcm_tech / Qiyan Nexus 进入可运行开发骨架前的早期规划产物。

当前开发事实源优先级：

1. `backend/`、`frontend/` 代码与测试
2. `README.md`
3. `AGENTS.md`
4. `CONTEXT.md`
5. `docs/current-state.md`
6. `docs/adr/`
7. 最新 `docs/handoffs/`

本目录内容仅作历史参考，不作为当前实现边界的直接依据。若本目录与当前代码、测试、ADR 或最新 handoff 冲突，以当前代码、测试、ADR 和最新 handoff 为准。

## 归档来源

- `Cursordos/`：早期 Cursor 驱动规划、前端设计、排期脚本与 HTML 原型。
- `Traedos/.trae/specs/tcm-platform-mvp/`：早期 Trae 需求、任务与验收清单。
- `Traedos/pre_cursor/`：进入 Cursor 前的重复规划快照。
- 顶层 `tcm_tech_plan_v2*.docx`：早期 Word 规划文档。

## 当前保留内容

- `specs/`：早期需求、任务与验收清单。
- `tcm_tech_plan_v2.docx`、`tcm_tech_plan_v2.1.docx`：早期 Word 规划快照。
- `tcm_tech_plan_v2.1_schedule.xlsx`：早期排期表。
- `tcm-platform-frontend-design.md`：早期前端设计文档。
- `prototypes/`：早期 HTML 原型。

## 使用规则

- 可用于追溯早期产品意图。
- 不应作为当前任务拆分、技术边界或验收标准的主入口。
- 新开发请优先读取 `docs/current-state.md`、`AGENTS.md`、`README.md`、`docs/adr/` 与最新 handoff。
